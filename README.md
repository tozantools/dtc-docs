# DTC (Direct to Cell) 技術情報集約

このリポジトリは、au Starlink DirectをはじめとするDTC（Direct to Cell、D2C）通信サービスに関する技術情報を集約・整理するためのドキュメントスペースです。

**利用場面**: 主に登山や沢登りなど、スマートフォンの地上基地局からの電波が届かない山間部での安全確保・緊急時通信手段としての利用を想定した情報を中心に記載しています。

**注意**: ここに記載される情報は非公式な調査・分析に基づくものであり、公式な技術仕様や正確性を保証するものではありません。

## スコープ

- **DTC技術概要**: 衛星から携帯電話への直接通信技術の仕組み
- **au Starlink Direct**: KDDIとSpaceXの提携によるDTCサービス
- **技術仕様**: 通信プロトコル、周波数帯域、カバレッジエリア
- **実装詳細**: ネットワーク構成、端末要件、サービス制限
